# Figure Promotion Plan

Updated: 2026-07-30

## Source Policy

- Promote reviewed July 2026 figures when they remain scientifically valid.
- Treat July 2026 as the minimum eligible provenance date for final figures.
- Prefer newer figures regenerated by the submission run whenever the underlying
  metric, algorithm, or comparison data changed.
- Treat the currently active March/May figures as historical layout and visual
  references only.
- Install only vector PDFs with no raster image objects.
- Keep the approved reconstruction language: clean and endpoint-labeled source
  variants, endpoint markers in zoom-ins, semantic corner diamonds, and
  nonoverlapping spyglasses.

The row-level map for all 26 active manuscript assets is
`submission/figure_provenance.csv`.

## Promote After The Final Sweep

| Figure family | Preferred source | Gate |
| --- | --- | --- |
| Five main metric panels | Regenerate the July layout from the final all-method CSV | Reconcile every caption and reported value with the final data |
| Five main representative reconstructions | July paired figures, or a newer replay of the same approved cases | Author selects clean or endpoint-labeled variant |
| Five resolution studies | Regenerate from final saved case artifacts | Confirm proposed cases and spyglass windows; move to supplement if approved |
| Five all-method panels | Regenerate from the final all-method CSV | Verify method colors, axes, legends, and vector output |
| PLIC stencil and staged reconstruction | Deterministic regeneration from the final clean commit | Visual comparison against the reviewed July versions |

## Conditional C0 Figures

The four C0 figures must be regenerated from the conservation-guarded
implementation. The matched 100-case rerun has no case above `1e-6` and a worst
global relative area error of `1.44e-10`. When adjusted endpoints cannot be
refit conservatively, the implementation retains the pre-C0 facet; captions
must therefore describe continuity as optional and conditional rather than
claiming that every eligible join is forced to close.

## Approval Sequence

1. Freeze the validated code commit and complete the final all-method sweep.
2. Regenerate metric, all-method, resolution, PLIC, and staged figures.
3. Replay representative cases from the final bundle and produce both endpoint
   variants.
4. Build one indexed review PDF containing every proposed replacement.
5. Record the author's per-figure selection in the approval CSV.
6. Replace manuscript assets, update `figure_provenance.csv`, and compile both
   primary and supplementary layouts.
7. Audit every active PDF for raster objects, clipping, overlapping insets, and
   caption/data mismatches before marking the result set frozen.
